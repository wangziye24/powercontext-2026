## 4) 混合检索 SQL（实际执行的核心查询）

```sql
SELECT c.chunk_id, c.heading, d.title,
       VECTOR_DISTANCE(c.embedding, %s) AS vdist,
       MATCH(c.content) AGAINST (%s IN NATURAL LANGUAGE MODE) AS kw_score
FROM chunks c
JOIN docs d ON d.doc_id = c.doc_id
WHERE c.course = %s
ORDER BY (0.7 * (1 - VECTOR_DISTANCE(c.embedding, %s))
        + 0.3 * MATCH(c.content) AGAINST (%s IN NATURAL LANGUAGE MODE)) DESC
LIMIT 10;
```

参数：`query_vector('[1536 维]')`、`query_text`、`course`。
