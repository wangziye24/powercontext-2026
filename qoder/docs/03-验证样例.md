## 样例 4：换关键词 / 换课程，验证过滤与混合打分真的生效

同一个查询 `向量时钟` 换课程过滤，实测输出（2026-10-27 真实运行）：

```
--- course=分布式系统
   分布式系统讲义.md | 第2章 一致性模型 / 2.3 向量时钟 | dist=0.2738 kw=3.8248 score=0.8083
   分布式系统讲义.md | 第1章 分布式系统概述 / 1.2 分布   | dist=1.2851 kw=1.4594 score=-0.0851
--- course=机器学习
   机器学习复习笔记.md | 第3章 常用算法 / 3.4 支持向量   | dist=1.1817 kw=0.9994 score=0.1728
   机器学习复习笔记.md | 第2章 模型评估 / 2.1 过拟合与   | dist=1.2529 kw=0.0000 score=-0.1771
```

判读要点（评审可据此核对"混合检索"确实在工作）：
- **结构化过滤生效**：`WHERE c.course = ?` 决定了结果只来自指定课程；
- **语义信号生效**：正确课程的 Top-1 `dist=0.2738`（远小于错误课程的 1.1817），即向量近邻确实更近；
- **关键词信号生效**：正确课程 `kw=3.8248`（ngram 全文命中"向量时钟"），错误课程 `kw≤1.0`；
- 注意：向量检索**总有近邻**，所以换课程后命中数不会变成 0，判断依据是 kw / dist 而非命中数。

其他常用查询：
```
search("如何缓解过拟合", course="机器学习") → Top-1《机器学习复习笔记.md》2.2 缓解过拟合的方法
search("倒排索引", course=None)            → Top-1《OceanBase全文索引优化.md》
```
