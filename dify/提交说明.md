## 三、技术结合怎么说（评审最关心的三句）

1. **Dify 承担核心编排**：14 个节点线性链路（意图判定 → 双路检索 → 角色生成 → 状态机 → 双写回 → 输出），
   节点级执行记录见 `dify/docs/evidence/node-trace.txt`（14/14 succeeded）。
2. **seekdb 实际发挥作用**：`nightstore.lore` 用 `DBMS_HYBRID_SEARCH`（向量 + 全文 + 结构化过滤，RRF 融合）
   实时挑设定，命中内容直接进阿夜的台词（例如"关东煮拼盘 18 元"来自库内条目）；
   `nightstore.player_state` / `nightstore.event_log` 记录每轮账本与事件流水；
   PowerContext 的记忆表 `powermem.memories` 也落在同一个 seekdb 实例。
3. **PowerContext 实际发挥作用**：每轮把值得记住的事写进记忆库，**新会话**里语义召回并写进台词
   （"记得，你上次想把薄荷糖标签换成『后悔药』"），玩家一句纠正还能把记忆改回来。

详见 `dify/docs/03-技术结合证据.md`。

## 四、评审 5 分钟上手路径

```bash
# 1) 三个服务
cd dify/deploy && docker compose -f seekdb.yml up -d seekdb
cd ../backend && cp .env.example .env && python3 -m app.main &
python3 -m app.seed                                   # 灌 35 条设定
python3 ../scripts/init_powercontext.py               # 准备 PowerContext 存储
#   （PowerContext 用仓库源码启动：python -m server.cli.server --host 0.0.0.0 --port 8848）

# 2) Dify
cd ../deploy/dify && cp .env.template .env && docker compose up -d

# 3) 一键自检（seekdb / 混合检索 / 状态 / 事件流水 / 记忆写入召回）
bash dify/scripts/smoke_test.sh

# 4) 导入 DSL + 配置模型 + 发布
python3 dify/scripts/dify_ops.py setup
python3 dify/scripts/dify_ops.py import
python3 dify/scripts/dify_ops.py publish --app-id <app_id>

# 5) 跑一遍完整玩法演示（生成对话记录）
python3 dify/scripts/demo_run.py --app-id <app_id> --out dify/docs/evidence/demo-transcript.md
```

## 五、玩法提示（给评审的"一分钟上手"）

1. 点推荐问题「关东煮还有吗？」→ 阿夜会报**库里的真实价格**（18 元）。
2. 说「我叫小李，以后每周三都来买热咖啡」→ 偏好被记住。
3. 说「把薄荷糖的标签换成『后悔药』怎么样？」→ 触发整蛊任务。
4. **点"新建对话"**（同一个玩家 ID）再问「你还记得我上次干了什么吗？」→ 她会翻旧账（跨会话记忆）。
5. 质疑她「不对，我上次明明是把薄荷糖换成了芥末糖」→ 她当场认错并把真话写回记忆。
6. 继续聊到好感度 30 / 60 / 85 → 章节推进（第二章·常客 → 第三章·熟客 → 第四章·合伙人）。
