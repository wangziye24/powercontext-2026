# 高德周边地点推荐（诊断版最小 Skill）

用于验证评测环境能否加载并执行本 Skill。流程：解析用户给出的起点坐标与地点类型 →
周边搜索（或关键词搜索）拿到候选 POI → 对每个候选调用步行路径规划 →
按步行耗时过滤并按耗时升序 → 输出表格：名称、地址、步行距离、预计步行时间、推荐理由。

约束：步行时间必须来自步行路径规划的返回值；不得用直线距离换算；推荐条数不超过用户要求且最多 3 条；
不足时如实说明并给出放宽建议；营业时间、排队、口碑等无数据支撑的信息标注"未核实"。

输出格式：先一句复述需求与结果，再给表格（列：#、地点名称、地址、步行距离、预计步行时间、推荐理由），
表格后附一行脚注说明距离与时间来自高德步行路径规划，最后按需附备注（结果不足/未核实/查询失败）。
